# 英语单词学习

单文件 SPA 词汇学习应用，支持四级 / 六级 / 考研 / 雅思等 8 套词库。

## 功能

- 词库浏览、搜索、收藏、考频排序
- 背词（自定义范围）、听写、自动朗读
- 注释隐藏（快捷键 H / X 偷看）
- PDF 导出（两列、含/不含注释、奇偶页分开打印）
- 移动端响应式适配

## 在线访问

部署在 GitHub Pages，直接用手机或电脑浏览器打开即可，可添加到主屏当 App 使用。

## 本地运行

任意静态服务器即可，例如：

```bash
python -m http.server 8000
```

然后打开 http://localhost:8000
